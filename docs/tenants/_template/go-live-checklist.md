# <店舗名> Go Live チェック

管理画面（`/admin/tenants/<storeId>`）の導入チェックリストと対応。
「利用モジュール」で使う機能を選ぶと、その機能のCritical項目がGo Live判定対象になる。

## 必須（Critical・使う機能に応じて）
- [ ] organization / store / slug / Owner / 営業時間
- [ ] テーブル（予約・POS利用時）
- [ ] メニュー・税・レジ（POS利用時）
- [ ] E2Eテスト完了
- [ ] セキュリティ確認
- [ ] 店舗オーナー確認
- [ ] Go Live承認

## 任意
- [ ] 定休日 / QR / コース / 支払方法 / ハードウェア / 勤怠 / 在庫 / 会計 / 操作説明
