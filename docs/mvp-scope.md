# MVPスコープ（フェーズ1）

> 本書は初期設計時のスコープ定義。POS/予約決済（Stripe）・KDS・QRオーダー・レシピ連動在庫減算は
> 本書がフェーズ2「未実装」とした時点から実装が進み、現在は`docs/future-integrations.md`の状態表が
> 最新の実装状況を示す（SaaS課金・プリンター実機・LINE/グルメサイト連携等は引き続き未実装）。

## 原則

全機能を浅く作らず、**予約→着席→注文→会計→売上→顧客履歴→レポート**の縦フローを最後まで動かす。

## フェーズ1（本リリースの対象）

1. 認証（Supabase Auth / メール+パスワード）
2. マルチテナント（organizations / stores / memberships + RLS）
3. 企業・店舗・ユーザー管理
4. 権限管理（10ロール × 機能別権限）
5. 店舗設定（営業時間・休業日・テーブル・フロア）
6. メニュー・商品設定（カテゴリ・価格・税率・売切）
7. オンライン予約（/book/[storeSlug]、空席判定、確認・変更・キャンセル）
8. 予約台帳（日/リスト/タイムライン表示、手動予約、ウォークイン）
9. テーブル割当・状態管理（フロアマップ）
10. 基本POS（商品タップ・数量・メモ・追加注文・取消）
11. 会計（現金/クレジット/QR/電子マネー/商品券/掛け、併用、内税外税、8%/10%、値引き、端数処理）
12. レシート表示・ブラウザ印刷・領収書・再印刷
13. レジ締め（開局/中間入出金/閉局/理論残高/差異/承認）
14. 小口現金（入出金・勘定科目・承認・月次残高）
15. 顧客管理（CRM基本、来店履歴・累計額自動更新、タグ・メモ・アレルギー）
16. 請求書・書類アップロード（Storage、支払状態管理、承認フロー）
17. タイムカード（出退勤・休憩・修正申請・承認）
18. 給与・歩合試算（勤怠集計×時給/月給＋歩合ルール→プレビュー、承認、CSV）
19. 本社ダッシュボード（全店合計・店舗比較・アラート）
20. 店舗別レポート（売上・商品・スタッフ・支払方法・時間帯、明細ドリルダウン）
21. CSV出力（売上・注文・顧客・勤怠・給与・小口現金・請求書）
22. 操作履歴（audit_logs、金額変更・取消・締め後修正）

補助: 通知基盤（アプリ内通知テーブル＋一覧UI、メールはResend等を後付けできる抽象化）、CYPRESS管理画面（企業・店舗・ユーザー・監査ログ・機能フラグ）、デモデータseed。

## フェーズ2（実装しない。ただし拡張可能なデータ構造を用意）

- プリンターSDK直接連携（Epson ePOS / Star WebPRNT）・キャッシュドロア・キッチンプリンター → `print_jobs` と抽象化レイヤーのみ用意
- LINE予約・通知、外部予約サイト連携 → `reservation_sources` で経路記録のみ対応
- 請求書OCR・ScanSnap自動取込 → `documents.ocr_status / ocr_payload` カラムを予約
- 会計ソフト・勤怠サービスAPI連携 → CSV出力で代替
- レシピ別在庫自動減算 → `menu_item_ingredients` を第2段階で追加できる在庫構造
- 正式な給与計算（税・社会保険・年調）→ 社労士・税理士確認後
- 会員ランク・ポイント・クーポン・メール/LINEマーケティング
- AI経営分析・多言語・課金管理（Stripe）

## MVP完成条件（受け入れテスト）

1. CYPRESS管理者が契約企業を作成できる
2. 契約企業が複数店舗を登録できる
3. 店長とスタッフを登録できる
4. 店舗ユーザーは他店舗を閲覧できない
5. 本社ユーザーは全店舗を閲覧できる
6. 一般客が公開予約ページから予約できる
7. 予約が店舗の予約台帳へ表示される
8. 予約をテーブルへ割り当てられる
9. 着席状態へ変更できる
10. 予約からPOS画面を開ける
11. 商品を注文できる
12. 現金・カード・QRの支払区分で会計できる
13. 会計後に売上へ反映される
14. 顧客の来店履歴へ反映される
15. 担当スタッフの実績へ反映される
16. レジ残高へ反映される
17. 日次締めができる
18. 本社ダッシュボードへ反映される
19. 請求書をアップロードして支払状態を管理できる
20. スタッフが出勤・退勤を打刻できる
21. 勤怠と売上から給与・歩合プレビューを作成できる
22. CSVを出力できる
23. 金額修正や取消が監査ログへ残る
24. 他企業のIDを直接指定してもデータを取得できない（RLS）
