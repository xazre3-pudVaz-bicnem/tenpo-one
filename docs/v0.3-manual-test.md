## 2. POS完成形（v0.3・約8分）

1. POSを開く → 検索ボックスに商品名の一部を入力 → ✅ 候補が絞り込まれる

## 問題があった場合

- 直前の安定版: タグ `checkpoint-pre-v03`
- 各機能の既知の制限: `docs/known-limitations.md`
- 外部依存でBLOCKEDの項目一覧: `docs/external-blockers.md`
- 実環境自動検証: `node --env-file=.env.local scripts/verify-flow.mjs`（103項目）
- Playwright全ルート巡回: `npx playwright test`（56ルート、console error検出）
