# FOGO オーナー様 初期設定ガイド（営業開始前）

TENPO ONE にログイン後、以下を **押す → 入力する → 確認する** だけで営業を開始できます。
（不明だった項目は空欄のままにしてあります。オーナー様の情報で埋めてください。）

ログイン: `https://www.tenpo-one.com/login` → メール＋初期パスワード（運営から安全な方法でお渡し）。
初回ログイン後、パスワードを変更してください。

---

## ★ 営業開始前に必要（これが揃うと本番稼働できます）

### 1. 店舗情報（設定 → 店舗情報）
- 住所・電話・席数・「オンライン予約を受け付ける」ON を確認 →〔保存〕

### 2. 営業時間・定休日（設定 → 営業時間）※現在【未設定】
- 曜日ごとの 開店〜閉店・ラスト入店（L.O.）を入力
- 定休日・臨時休業を登録 →〔保存〕
- ※ これを入れないと Web予約の空き枠が出ません。

### 3. 予約設定（設定 → 予約設定）※一部【未設定】
- 標準滞在時間・予約枠間隔・予約受付締切・キャンセル期限
- **キャンセルポリシー**・ご予約時の注意事項（公開ページに表示）
- 店舗写真URL（任意）
- 公開予約URL・**QRコード**（Google/Instagram/LINE/店舗HPに掲出）
- 「席のみ / コース」両対応で設定済み（変更可） →〔保存〕

### 4. テーブル（設定 → テーブル管理）※【要確認】
- T1〜T15（総席102）を登録済み。席数・名称・配置を確認・修正
- 各卓の **QRコード** を表示・印刷して卓に設置（席に応じて再発行/無効化可）

### 5. メニュー・コース（設定 → メニュー）
- コース6・料理38・ドリンク86（計130）を登録済み（食べログ参考）
- **価格未設定 2件**（バニラアイス・ティラミス）に価格を入力 →〔販売中〕へ
- 価格・説明・カテゴリ・並び順・売り切れ（ワンタップ）を確認
- コースの 人数条件・利用時間・公開/非公開・並び替え を確認

### 6. 支払方法・税（設定）※税【未設定】
- 消費税（標準10%/軽減8%）を設定
- 支払方法（現金・クレジット等）を確認
- **stera（JT-C60）は手動決済確認方式**：TENPO ONEで金額を確認 → JT-C60で決済 →
  成功を確認してから TENPO ONE で会計確定（会計方法=クレジット）

### 7. スタッフ（スタッフ管理）※【未登録】
- スタッフを招待し、権限（店長/スタッフ等）とPINを設定

## ◇ 後からでもよい（営業しながら整備）
- 在庫・原価・仕入先 / 勤怠・シフト / 給与 / 会計
- プリンター（Star mC-Print3系）の型番・IP・接続確認
- キャッシュドロアの接続確認
- 商品写真の追加

---

## 使い方の流れ（イメージ）
```
お客様: 予約（席のみ/コース）→ 来店 → 着席
店舗:   台帳でテーブル割当 → 着席 → お客様が卓のQRでモバイル注文
        → 厨房(Kitchen)/ドリンク(Bar)へ表示(KDS) → 提供
会計:   金額確認 → stera JT-C60で決済 → 成功確認 → TENPO ONEで確定
        → 売上・顧客(CRM)へ反映 → レジ締め
```

不明点は運営（CYPRESS）までご連絡ください。設定は後からいつでも変更できます。
