   - ✅ ステータスを 来店待ち → 来店 → 着席 と進められる（不正な遷移ボタンは出ない）

## 2. QRオーダー → KDS（約5分）

1. 設定 → フロア・テーブル → T3の「QRコード」→ ✅ QR画像とURLが表示 → URLをコピー
2. シークレットウィンドウ（スマホ幅推奨）でURLを開く
   - ✅ ログインなしでメニュー表示・「おすすめ」タブ・売切品はグレー
   - 商品を選び（オプションがあれば選択）→ カート → 注文
   - ✅ 「注文を受け付けました」→ 注文履歴に品目と状態表示
3. 店長画面 → キッチン（KDS）
   - ✅ QR注文のカードが出る（QRバッジ付き）。**手動更新なしで自動的に現れること（Realtime）**
   - ✅ ステーションタブ（キッチン/ドリンク）で振り分け表示
   - 調理開始 → 完成 → 提供済 と進める → ✅ 客側の注文履歴の状態も追従（10秒以内）
4. POS → 該当テーブルの伝票を開いて会計（現金）→ テーブルが清掃中→フロアで「清掃完了」

## 3. レジ締め（約5分）

1. 店長 → レジ・小口現金 → レジタブ
   - 未開局なら「開局」（釣銭3万円）※既に開局済ならそのまま
2. 上記1・2の現金会計後 → 「レジ締め」
   - ✅ 理論現金 = 開始現金+現金売上−現金返金±入出金 が自動表示
   - 実残高に理論値と同額を入れて締め → ✅ 差異0
   - 実残高をわざと100円ずらすと → ✅ 差異表示+理由必須
3. 締め履歴タブ → ✅ 本日分が表示・承認できる
4. 小口現金タブ → 出金1,200円（消耗品費）登録 → 経理でログインし直して承認
   - ✅ 「実残高を数える」で実査 → 差異が計算される
