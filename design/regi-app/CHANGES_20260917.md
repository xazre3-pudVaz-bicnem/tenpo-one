## 3. 配色・ラベル
- 配色は **紫（B）のまま**（ロニー確定）: plum #241436（トップバー・ログイン）/ royal #5B2C8F / iris #7B3FE4 / iris-soft #E9E0FA / lilac #EFEAF8（背景）/ line #E3DBF1 / saffron #BD660F（金額）/ good #1E8F62 / alert #B3341F。B のトークンをそのまま使用（`build.py` の `PALETTE=A` で tenpo-one 配色版にも切替可: navy #0f1120・#7b3ff2・#f2f4f7・#ea580c）
- 状態色: 着席=薄紫／注文済=紫／L.O.済=黄 #E0AE00／時間超過=赤／会計待ち=橙／空席=破線

- フォント: Noto Sans JP（数字は tabular-nums）。ブランド表記は「TENPO ONE レジ」（帳票フッターも）。カテゴリ色（レールのドット／商品カード上辺）は新規追加

## 4. 実装メモ（仕様書 第3・4章準拠）
- データモデル・関数名は B のまま: TABLES/CAP/ORDERS/RESV/CUSTOMERS/SLIPS/CASH/STOCK/SITES/MESSAGES/VENDORS/BILLS/DELIV/MONTHS/ACCT/SCANS/PAY_MEMORY/DEVICES/HANDIES/MO、`go()`/`updateChrome()`/`showOrderView()`/`tableTile()`/`applyResvMove()`/`processScan()`/`autoFix()`/`registerScan()`/`settleAdvance()`/`printReport()`/`mfExport()`/`collectAlerts()`/`todoItems()` など
